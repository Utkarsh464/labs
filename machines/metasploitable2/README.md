# Metasploitable 2 Labs

Metasploitable 2 is an intentionally vulnerable Linux virtual machine used for controlled security training. The labs in this section document exploitation workflows against that machine in an isolated virtual network.

## Labs

| Lab | Primary Service | Vulnerability | Status |
| --- | --- | --- | --- |
| [vsFTPd 2.3.4 Backdoor](vsftpd-2.3.4-backdoor/README.md) | FTP | CVE-2011-2523 | Complete |
| [DVWA Brute Force](dvwa-brute-force/README.md) | HTTP | Weak credentials | Complete |

## Safety Boundary

These labs are written for educational use inside an intentionally vulnerable environment. The techniques should not be used on systems without explicit authorization.
