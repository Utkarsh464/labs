# Metasploit Labs

Hands-on penetration testing labs using Metasploit, Nmap and intentionally vulnerable machines.

> These labs are performed in an isolated, intentionally vulnerable environment for educational purposes.

## Repository Scope

This repository documents practical penetration testing exercises with a focus on:

- Enumeration
- Vulnerability assessment
- Exploitation workflow
- Troubleshooting
- Post-exploitation validation
- Professional reporting

- Attacker machine: Linux penetration testing workstation
- Target machine: Metasploitable 2
- Tools: Nmap, Zenmap, Metasploit Framework, Netcat
